# Adoptante «Elige a tu compañero» (#420)

Capturas del flujo nuevo del adoptante a **390 px** (celular) y **1366 px** (computador), tomadas
con el sistema local y los datos de demostración. Los animales de la demostración no tienen foto,
así que se ven con su ilustración e inicial; con fotos en el catálogo, la foto ocupa ese lugar.

| Archivo | Pantalla |
|---|---|
| `*-1-bienvenida` | Bienvenida con collage y animalitos caminando |
| `*-2-encuesta-especie` | Primera pregunta (solo filtra en pantalla) |
| `*-2b-encuesta-precargada` | Pregunta del perfil con la respuesta ya guardada marcada |
| `*-3-combinan` | «¡Ellos combinan contigo!» con el puntaje del servidor |
| `*-4-elegir` | «Elige a tu compañero» |
| `*-5-listo` | «¡Lo elegiste!» recién enviada |
| `*-6-solicitudes` | Mis solicitudes |
| `*-7-solicitud-aprobada` | Mis solicitudes con una adopción aprobada |
| `*-8-listo-aprobada` | Pasos de una solicitud aprobada, con el compromiso en PDF |

Las capturas se tomaron con `animations: "disabled"`: el movimiento (rebotes, confeti y
animalitos) no se ve aquí.
